Admin commands

Commands for the server's admins and owner. Anyone else who tries one gets "You do not have permission". Type !bot in the server or channel chat first, then send these in its private chat. Everyone's commands are on the Commands page. Tip: click any command to copy it.

Help

!helplistadmin
Lists the admin commands in chat, one line each. !help points admins to it.

Donations

Admins.

!donation add <name> <pounds> [date]
Records a donation in whole pounds, up to the per-person limit for this donation window, and gives out what it earns: 1 banner week and 1 modal week per £1, plus the mute once that person's donations in the window reach the mute minimum. The date is optional (today if left out), written day first, and must fall inside the donation window and not in the future. Refused once the goal is reached, unless that's switched off. Put names with spaces in quotes. The reply gives the donation's number, in case it needs voiding.
Example date: 05/10/2026
!donation void <number>
Reverses a donation by its number. Takes back the weeks it added, never below zero and not weeks already started. Takes back its mute only if it's unused and the person's window total drops below the mute minimum. Lowers the total raised. A donation can only be voided once.
!donation list [name]
Shows the latest donations, newest first, or just one person's. Marks voided ones and ones that gave a mute.

Checking the bot's files

Admins.

!sync
Re-reads the perks and donations files from the website and the private list of linked accounts, sends any changes still waiting for the website, and says whether each file passes its checks. A file that fails is rejected and the bot keeps using the last good copy. While the perks or donations file is rejected, the commands that change it refuse: fix the file, run !sync to check it passes, and they work again. Also says when the website was last read. Use it after editing a file by hand. Online admins get a private message whenever a file is rejected.

The website's records

Admins. These change the website's files for you, so there's no need to edit them by hand. Each reply shows the old and new value, every change goes in the audit log, and the website shows it about 10 minutes later. Put names with spaces in quotes.

!site show
Shows the total raised, the goal, the thresholds, the donation window and how many people are listed.
!site set <setting> <value>
Changes one setting: raised or goal (pounds, pence allowed, like 12.50); adminMinimum, muteMinimum or maxPerPerson (whole pounds); closeWhenGoalReached (on or off). Warns if muteMinimum is above maxPerPerson, since then nobody could earn a mute.
!site set window <month> <day> <days>
Sets when the donation window opens each year and how many days it lasts, counting the first. The month can be a number or a name.
Example: !site set window October 1 31
!donor add <name> [level]
Adds someone to the Supporters list, with an optional level (any text, several words allowed). !donation add already adds new donors, without a level.
!donor level <name> <level|none>
Gives a donor a level, or takes it off with none. For example when they reach the admin minimum and get the role in TeamSpeak.
!donor remove <name>
Takes someone off the Supporters list. Their perks stay.
!perk set <name> <banner|modal|mute> <value>
Fixes someone's perks by hand. Banner and modal are whole weeks not yet started. A mute is ready, none, or the date it comes back, day first. A name that isn't in any file yet is accepted, with a warning in case it's a typo.
Example: !perk set Bob mute 01/04/2027
!perk remove <name>
Takes all of someone's perks away, but not while one of their weeks is running.
!identity add <name> <user>
Links the TeamSpeak account of someone online now to a supporter, so they can use their perks. Part of their nickname is enough. One person can have several accounts linked, one per computer or phone, but each account can belong to only one person. The list stays private on the bot's computer and never goes on the website.
!identity add <name> uid <ID>
The same for someone who's offline, using their TeamSpeak unique ID. They can get it with !whoami.
!identity list <name>
Shows the accounts linked to a supporter.
!identity remove <name> <ID>
Unlinks one account from a supporter.
!uid <user>
Shows the unique ID of someone online, and who it's linked to.
!audit [how many]
Shows the latest audit log entries, newest first: 10 unless you say, at most 50. Each says when, what, who did it ("the bot" for automatic things) and the details.

Modal and banner

Owner only, except !modal remove and !banner remove, which Super Admins can use too. The owner never has to start a week, and the bot never refuses them because someone else holds the modal or banner.

!modal default <text> / !modal default off
Sets your everyday modal, shown whenever nobody has a week running. If someone does, it waits and shows by itself when their week ends. off means no pop-up when nobody has a week.
!banner default <picture address> [link] / !banner default off
The same for the banner. Any picture site works for your own banner. off means no banner.
!modal service <text>
Puts up an important service modal at once, above everything else. If someone holds the modal, their week pauses, so they lose no time, and they're told. Nobody can start a modal week while it's up. Send it again to change the text.
!modal service off
Takes the service modal down. The holder's message comes back and their week picks up where it left off.
!modal remove
Takes a rude modal off the server. No pop-up shows until the holder puts up a new one. Their week keeps running, and they're told it was removed for moderation reasons.
!banner remove
Swaps a rude banner for your everyday one. Their week keeps running, and they're told.
!control revoke <modal|banner>
Owner only. Ends someone's week early and brings your everyday one back. The rest of their week isn't refunded: to give it back, add a week with !perk set.

When a Super Admin removes something, the holder's message doesn't name them, and the owner's online accounts are told who did it. Every action goes in the audit log. If you change the modal or banner by hand in TeamSpeak while nobody has a week running, the bot keeps it as the new everyday one. During someone's week, it puts theirs back within 30 seconds.

Locked channels

!locks
Admins. Lists every locked channel: who locked it and when, who's in it, and who has stepped out.
!unlock <channel>
Super Admins and the owner can end any lock from anywhere on the server. That's how a Super Admin unlocks, since they can't walk into a locked channel. Part of the name is enough.

The owner can walk into a locked channel without joining the lock. Nobody can poke, message, move, kick or ban the users inside, the owner's account included; only YATQA logged in as serveradmin can. If the owner drags someone into a locked channel who doesn't belong there, the bot moves them out again.

Twitch

Admins. Online admins get a message when someone asks to link a channel.

!twitch pending
Lists links waiting for approval.
!twitch approve <channel or name>
Approves a link. Check it really is their channel first. If that channel is already linked to someone else, the reply says so.
!twitch deny <channel or name>
Turns a link down. They're told.
!twitch list
Every approved link, who's on the Live now page, and who's live right now. It also says if checking Twitch is switched off.
!twitch remove <channel or name>
Removes someone's link, and their [LIVE] tag with it. They're told.

Trivia

Owner only.

!trivia reset <name>
Takes someone off the leaderboard, for example if they cheated. Part of the name as it shows on the leaderboard is enough; they don't need to be online.
!trivia reset all
Wipes the whole leaderboard. The bot asks you to send !trivia reset all confirm first.

Uno

Owner only.

!uno reset <name> / !uno reset all
The same as for trivia, for the Uno leaderboard.
!uno games
The last 10 games with their numbers: who played, who won and how many points, or whether it's still going. Each game's number is also in its first message.
!uno void <number>
Against cheating. A game still being played ends at once and nobody scores. A finished game stops counting, so the winner loses exactly the points it gave them.

Community channels

The owner and Super Admins can use !role and !pull in any community channel, from inside it. The everyday uses are on the Commands page.

!role add <name> leader
Owner only. Makes someone the channel's Community Leader, the top role above Channel Admin. Only the owner can give, change or remove it: nobody else, Super Admins included, can remove or demote a Leader. If the role isn't set up yet, the bot says so.
!pull <name>
Only the owner can pull a Community Leader out of their own channel.
